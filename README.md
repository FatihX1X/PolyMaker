# PolyMaker

TapeOut motion-design films, produced entirely in code (Canvas 2D → headless Chromium → ffmpeg). Each film has Turkish and English versions.

- [`promo/`](promo/README.md): TapeOut promo film (76 s)
- [`deweb/`](deweb/README.md): TapeOut DeWEB explainer (93 s)
- `shared/motion.js`: shared motion toolkit (easing, typography, schematic, logo, HUD, subtitles)
- `tools/`: `render.mjs` (frame-by-frame MP4), `synth.mjs` (procedural sound), `subtitles.mjs` (SRT/VTT)
